# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] — 2026-07-30

### Added

- Include **Peacock** (`johnpapa.vscode-peacock`) in the pack under the editor tooling group. Peacock colour-codes each VS Code window, which is especially valuable for SI partners juggling several SFMC client projects at once, so you always know at a glance which project a window belongs to.

## [0.1.2] — 2026-06-18

### Added

- Include **MSO Conditionals** (`joernberkefeld.mso-conditionals`) in the pack, grouped with the other SFMC extensions. The README and description now list it alongside SFMC Data Loader, SFMC DevTools, and SFMC Language Service.

## [0.1.1] — 2026-04-14

### Fixed

- Marketplace: renamed display name to **SFMC Extension Pack Plus** so it is not rejected as too similar to Microsoft’s “Salesforce Extension Pack (Expanded)”.

## [0.1.0] — 2026-04-14

### Added

- Initial release: SFMC Data Loader, SFMC DevTools, SFMC Language Service, plus ESLint, Prettier, and EditorConfig.
